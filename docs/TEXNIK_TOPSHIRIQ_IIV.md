# ТЕХНИК ТОПШИРИҚ
## «Ziyrak AI Tergov» — Тергов ва суд-экспертиза ишларини қўллаб-қувватлаш дастури

**Ишлаб чиқарувчи:** (тулдирилади)  
**Буюртмачи:** Ўзбекистон Республикаси Ички ишлар вазирлиги  
**Ҳужжат тури:** Техник топшириқ (батафсил)  
**Тил:** Ўзбек  
**Ҳужжат версияси:** 1.0

## 1. УМУМИЙ ҚИСМ

### 1.1 Дастурнинг мақсади ва доираси

«Ziyrak AI Tergov» (кейинчалик — Дастур) — тергов ходимлари, суд-экспертлар ва ИИВ тизимидаги бошқа мутахассислар учун ягона веб-дастур. Дастур тергов жараёнларини (сўроқ, гувоҳлик, юзлаштириш), аудио/видео материалларни таҳлил қилиш, фоторобот ва эксперт-визуаллаштириш ишларини қўллаб-қувватлайди; шунингдек, ёрдамчи AI (виртуал мураббий), шаблон ҳужжатлар ва норматив-ҳуқуқий маълумотлар билан ишлаш имкониятларини тақдим этади.

Дастур фақат веб-браузер орқали ишлайди; серверга ўрнатиш талаб этилмайди (клиент тарафда ишлайди, маълумотлар локал сақланади, API орқали ташқи AI хизматларга мурожаат қилинади).

### 1.2 Фойдаланувчи категориялари

- Тергов ходимлари (сўроқ олиш, баённома тузиш)
- Суд-экспертлар (аудио таҳлили, видео/расм экспертзаси)
- ИИВ бошқармаларидаги бошқа мутахассислар (ҳужжат тузиш, шаблонлар, норматив база)
- Олий ўкув юртлари ва курсларда ўқитувчилар (виртуал мураббий, симулятор)

### 1.3 Техник асос

- **Интерфейс тили:** Ўзбек (кирилл ёзуви) — барча экран матнлари ва хабарлар шу тилда.
- **Ишлаш муҳити:** Замонавий веб-браузерлар (Chrome, Edge, Firefox, Safari — сўнги версиялар).
- **Сахна:** Десктоп ва планшет; мобил браузерда ишлаши қўллаб-қувватланади, лекин асосан десктоп учун мўлжалланган.

## 2. ТИЗИМ ТУЗИЛИШИ ВА КИРИШ

### 2.1 Авторизация (кириш)

- Дастурга кириш фақат логин пароль орқали амалга оширилади.
- **Логин ва пароль:** Администратор томонидан берилади; истакка кўра `.env` файлида (`LOGIN_USER`, `LOGIN_PASSWORD`) ёки демо маълумотлар (масалан: admin / 123) орқали белгиланади.
- **Хавфсизлик:** Пароль майдонида Caps Lock ёқилганлиги ҳақида огоҳлантириш чиқади; нотўғри киришлар сони чегараланган (масалан: 5 мартадан сўнг блокировка).
- **Сессия:** Мuvaffaqiyatli киришдан сўнг авторизация браузернинг локал хотирасида (`localStorage`, калит: `TERGOV_AI_AUTH`) сақланади; браузер ёки вкладка ёпилганда ҳам сессия сақланади, то ки чиқиш (logout) амалга оширилмагунча.
- **Чиқиш:** Профил ёки бошқа joyдаги «Чиқиш» тугмаси орқали чиқиш; тасдиқ модал ойнаси кўрсатилади, тасдиқлангандан кейин локал сақланган авторизация ўчирилади ва логин саҳифасига қайтилади.

Дастур кодига таъсир қилмайди: фақат ҳужжатда авторизация талаби ва ишлаши тавсиф этилади.

### 2.2 Маршрутизация (навигация)

- Дастурда алohида URL маршрутизация (Hash-based routing) ишлатилади: барча саҳифалар `#/...` қисми орқали аниқланади (масалан: `#/dashboard`, `#/protocol`, `#/stenogram`).
- **Асосий саҳифа (Dashboard):** `#/dashboard` — киришдан кейин фойдаланувчи ана шу саҳифага йўналтирилади.
- **Модулларга ўтиш:** Ҳар бир модул учун битта хеш йўли мавжуд; модул танланганда браузер манзили ўзгариши мумкин (масалан: `#/protocol`), «Орқа» тугмаси босилганда асосий саҳифага қайтиш.
- **Модул рўйхати (хеш йўллари):**
  - `#/dashboard` — Бош панел
  - `#/documents` — Архив (ҳужжатлар)
  - `#/stenogram` — Стенограмма (аудио таҳлили)
  - `#/protocol` — Ақлли баённома (жонли сўроқ)
  - `#/photorobot` — Фоторобот
  - `#/mentor` — Виртуал мураббий
  - `#/accident` — Автохалокат визуаллаштириш (видео экспертза)
  - `#/templates` — Шаблонлар
  - `#/settings` — Созламалар
  - `#/legal` — Ўқиш зали / ҳуқуқий қидирув
  - `#/statistics` — Статистика
  - `#/profile` — Профил

Дастур кодига таъсир қилмайди: фақат фойдаланувчи қандай саҳифаларга ўтиши тавсиф этилади.

### 2.3 Умумiy интерфейс элементлари

- **Ҳавотий панел (Footer):** Экранинг pastki қисмида авторлик, платформа номи («Ziyrak AI Tergov») ва техник маълумотлар кўрсатилади.
- **Хатоликлар:** Агар модул ичида ножида хатолик юз бериб кетса, «Modul xatosi» деган fallback экран чиқади ва «Орқа» орқали бош саҳифага қайтиш имконияти берилади.
- **Тост-хабарлар:** Ҳар хил амаллар учун қисқа хабарлар (муваффақият, хатолик, маълумот) экраннинг белгиланган joyида кўрсатилади ва вақт ўтиши билан ўзи ёкилади; бир нечта тўпда кўрсатиш чегараси (масалан: 5 та) бор.

Дастур кодига таъсир қилмайди: фақат UI тажрибаси тавсиф этилади.

## 3. БОШ ПАНЕЛ (DASHBOARD)

### 3.1 Мақсад

Фойдаланувчи киргандан кейин кўрадиган асосий саҳифа; барча модулларга тез кириш, қисқача маълумотлар ва охирги фаолликни кўрсатади.

### 3.2 Элементлар

- **Сарлавха ва салём:** Платформа номи ва фойдаланувчига мурожаат.
- **Вақт:** Жорий вақт (соат, дақиқа) кўрсатилади.
- **Ҳаво ва joy:** Фарғона шаҳри учун ҳаво (температура, қисқа тавсиф) ташқи API (Open-Meteo) орқали олинади ва кўрсатилади.
- **Хабарномалар панели:** Хабарномалар рўйхати; хар бири учун «ўқилди» белгилаш ва тозалаш имконияти; хабарнома тури (маълумот, ogohlantirish, муваффақият) кўрсатилади.
- **Модул карточкалари (Bento grid):** 6 та асосий модул учун алоҳида карточка:
  - Ақлли баённома (жонли сўроқ)
  - Стенограмма (аудио таҳлили)
  - Видео экспертза (автохалокат)
  - Фоторобот
  - Виртуал мураббий
  - Архив
- Карточкага босилганда тегишли модул саҳифаси очилади.
- **Охирги фаоллик:** Сақланган ҳужжатлар рўйхатидан сўнггилар кўрсатилади; уларни очиш имконияти.
- **Тез ссылкалар:** Шаблонлар, Ўқиш зали / ҳуқуқий қидирув, Статистика, Созламалар — уларга бир кликда ўтиш.
- **Профил:** Аватар ёки профил тугмаси орқали Профил саҳифасига ўтиш.

Дастур кодига таъсир қилмайди: фақат бош панел функционаллиги тавсиф этилади.

## 4. АҚЛЛИ БАЁННОМА (SMART PROTOCOL) — ЖОНЛИ СЎРОҚ

### 4.1 Мақсад

Сўроқ пайтида жонли аудио ёзувни олиш, уни сақлаш (ижро иши рақами бўйича), матнга айлантириш (транскрипция), суҳбатдошларни ажратиш ва расмий баённома (Word-га мос HTML) яратиш.

### 4.2 Протокол турлари

Дастурда қуйидаги тергов турлари қўллаб-қувватланади (конфигурация файлида аниқланади):

- Гувоҳни сўроқ қилиш (ЖПК 66-модда)
- Жабрланувчини сўроқ қилиш (ЖПК 96-модда)
- Гумон қилинувчини сўроқ қилиш (ЖПК 112-модда)
- Айбланувчини сўроқ қилиш (ЖПК 112-модда)
- Юзлаштириш баённомаси (ЖПК 123-модда)

Ҳар бир тур учун расмий сарлавха, ҳуқуқий маълумот (модда) ва рол матни кірғизилади.

### 4.3 Метамаълумотлар (анкета)

Баённома яратишдан олдин тўлдирилади:

- Ижро иши рақами
- Шаҳар, сана, бошланиш ва тугаш вақти
- Сўроқ олувчи (исм, унвони, кабинет рақами)
- Сўроқ қилинаётган шахс (исм, туғилган йили, joyи, миллати, фуқаролиги, таълим, иш жойи, манзил, оилавий аҳволи, жиноий жавобгарлик бўйича маълумот)
- Иштирокчилар рўйхати (рол, исм)
- Истакка кўра: адвокат исми

Бу маълумотлар баённома HTML ичида расмий кўринишда чиқади.

### 4.4 Жонли ёзув

- **Бошлаш / Тўхтатиш:** Микрофон орқали ёзув бошланади ва тўхтатилади; тўхтатилганда аудио сақланади.
- **Сақлаш:** Ёзув ижро иши рақами билан IndexedDB да (махсус база: `TERGOV_SOROQ_AUDIO_DB`) сақланади; бир нечта ёзув сақланиши мумкин (ҳар бири ижро рақами, сана, давомийлик билан).
- **Кўриниш:** «Жонли юзиш» ва «Аудио ёзувлар» деган икки таб; «Аудио ёзувлар» табида барча сақланган ёзувлар жадвалда кўрсатилади: ижро иши рақами, сана, давомийлик, эшитиш тугмаси, ҳар бир қатор охирида «Баённома яратиш» тугмаси; истакка кўра ёзувни ўчириш имконияти бор.

### 4.5 Баённома яратиш жараёни

- Фойдаланувчи жадвалдан бирор ёзувни танлайди ва «Баённома яратиш» ни босади.
- Аудио серверга (OpenRouter/Gemini ёки Groq Whisper) юборилади, матнга айлантирилади (узун ёзувлар учун қисм-қисм ишлаши мумкин).
- AI ёрдамида суҳбатдошлар (спикерлар) аниқланади; матн сегментларга бўлинади (вақт белгиси билан).
- Тўплаangan маълумотлар ва танланган протокол тури асосида расмий баённома HTML ишлаб чиқилади (савол-жавоб формати, ҳуқуқий кириш матни, анкета маълумотлари).
- Натижа экранда кўрсатилади; Word-га импорт қилиш учун HTML файл сифатида юклаб олиш имконияти бор.

Дастур кодига таъсир қилмайди: фақат ақлли баённома модулининг иш тарзи тавсиф этилади.

## 5. СТЕНОГРАММА (АУДИО ТАҲЛИЛИ)

### 5.1 Мақсад

Тайёр аудио файлни юклаш, матнга айлантириш (транскрипция), суҳбатдошларни номлаш ва таҳрирлаш, кейинчалик экспорт ёки архивга сақлаш.

### 5.2 Қабул қилинадиган форматлар

MP3, WAV, M4A, OGG, FLAC, WebM ва бошқа браузерда қўллаб-қувватланадиган аудио форматлари; файл ҳажми чегараси (масалан: 25 МБ) кўрсатилади.

### 5.3 Транскрипция

- Файл юклангандан кейин «Транскрипция» (ёки аналогик) тугмаси босилади.
- Транскрипция ташқи API орқали бажарилади: OpenRouter (Gemini) ёки Groq (Whisper); API калити бўлмаса Groq ишлатилади.
- Натижа сегментлар рўйхати сифатида кўрсатилади: ҳар бир сегментда спикер номи, матн, вақт белгиси.

### 5.4 Таҳрирлаш

- Спикер номини ўзгартириш: ҳар бир сегментда номни таҳрирлаш имконияти; биринчи иштирокчи номи тўлиқ ўчирилиб, бошқа ном ёзиш мумкин эмаслиги (ёки маълум чегараларда) таъминланади.
- Сегментни ўчириш: керак бўлса сегмент ўчирилади.
- Word-га экспорт: диалогларда вақт белгиси фақат бир марта (қатор бошида) чиқади, такрорланмайди.

### 5.5 Протокол маълумотлари ва архив

- Стенограмма учун ҳам протокол тури ва метамаълумотлар (сана, шаҳар, сўроқ олувчи ва ҳ.к.) киритилади.
- Тайёр матн HTML ёки бошқа форматда экспорт қилиниши ёки «Архивга сақлаш» орқали сақланиши мумкин; категория — STENOGRAM.

Дастур кодига таъсир қилмайди: фақат стенограмма модулининг иш тарзи тавсиф этилади.

## 6. ФОТОРОБОТ

### 6.1 Мақсад

Шахс (гумонланувчи/жабрланувчи ва ҳ.к.) ёки predmet (пічоқ, автомашин, бино, телефон ва ҳ.к.) учун AI ёрдамида реалистик расм вариантлари яратиш, танлаш, матн орқали таҳрирлаш ва архивга сақлаш.

### 6.2 Мақсад турлари

- **Инсон:** Йуз композит — жинс, ёш, ирқ/миллийлик, тери ранги, йуз шакли, кўз, бурун, соч, соқол, кийим ва бошқа белгилар параметрлар ёки матн (тавсиф) орқали киритилади.
- **Предмет:** Автомобил, бино/иншоот, мобил телефон, qurol/пічоқ — категория бўйича параметрлар (ранг, тури, марка, материал, шикастлар ва ҳ.к.) ёки эркин матн тавсифи.

### 6.3 Кириш усуллари

- **Параметрик:** Тўлдирувчи форма — инсон учун йуз/танa параметрлари, предмет учун категория ва деталлар.
- **Тавсиф (Narrativ):** Матн майдонида эркин тавсиф ёзилади.
- **Овозли киритиш (истакка кўра):** Браузерда Web Speech API орқали овозни матнга айлантириб, таҳрир матнига қўшиш.

### 6.4 Генерация ва танлаш

- «Яратиш» тугмаси босилганда ташқи расм генерация API (OpenRouter — Gemini/Flux ва ҳ.к.) чақирилади; 5 та вариант яратилади.
- Инсон учун: портрет, оқ фон, реалистик йуз деталлари.
- Предмет учун: фақат айтилган битта предмет, оқ фон; автомашин, кўл ёки бошқа объектлар қўшилмайди (масалан: пічоқ — фақат пічоқ, автомашинa билан бирга эмас).
- Фойдаланувчи бирор вариантни танлайди; кейин «Таҳрирлаш» режимида матн орқали ўзгаришлар киритиб, янги расм яратилади; Undo/Redo имконияти бор.

### 6.5 Сақлаш

Танланган расм «Архивга сақлаш» орқали сақланади; категория — PHOTOROBOT, тег — AI ва мақсад тури (инсон/предмет).

Дастур кодига таъсир қилмайди: фақат фоторобот модулининг иш тарзи тавсиф этилади.

## 7. ВИРТУАЛ МУРАББИЙ (VIRTUAL MENTOR)

### 7.1 Мақсад

Тергов ва суд ишлари бўйича савол-жавоб, режалаштириш, симуляция ва ҳуқуқий маълумот олиш учун AI чат; ёнда «Академия» (курслар, китобхона, викторина) ва шаблонларга ссылка.

### 7.2 Режимлар

- Умумий (жавоблар умумiy)
- Режалаштирувчи (тергов режаси, қадамлар)
- Симулятор (сценарий бўйича жавоблар)
- Квалификатор (баҳолаш, таклифлар)
- Танқидчи (критика, заиф томонлар)
- Ҳуқуқий қидирув (норматив ва суд амалиёти бўйича жавоблар)

### 7.3 Чат

- Фойдаланувчи матн ёзади; AI жавоб Ўзбек (кирилл) тилида қайтарилади.
- Ўтган хабарлар саҳифада сақланади (сессия давомида).
- Истакка кўра овозли киритиш (Web Speech API).

### 7.4 Академия

- Курслар рўйхати: мавзу, даража, давомийлик, мавзулар.
- Китобхона: ҳуқуқий қидирув — матн сўров бўйича мақола ва прецедентлар қидирилади.
- Викторина: саволлар ва жавоблар орқали тест; натижа ва түшунтириш кўрсатилади.
- Шаблонларга ўтиш: тугма орқали Шаблонлар модули очилади.

## 8. АРХИВ (ҲУЖЖАТЛАР)

### 8.1 Мақсад

Барча сақланган ҳужжатларни (стенограмма, баённома, фоторобот, видео экспертза ва ҳ.к.) бир joyда кўрсатиш, қидирув, очиш ва керак бўлмаса ўчириш.

### 8.2 Маълумот манбаи

Ҳужжатлар браузернинг локал хотирасида (localStorage, калит: `TERGOV_AI_DB_V1`) сақланади; серверга юборилмайди.

### 8.3 Функциялар

- **Рўйхат:** Барча сақланган ҳужжатлар сарлавха, категория, сана билан рўйхатда кўрсатилади.
- **Қидирув:** Сарлавха бўйича матн қидирув.
- **Батафсил:** Ҳужжат танланганда унга тетишли маълумотлар (сарлавха, категория, тавсиф, контент, медиа ссылка, сана) кўрсатилади.
- **Ўчириш:** Ўчириш тугмаси босилганда тасдиқ модали чиқади; тасдиқлангандан кейин ҳужжат localStorage дан ўчирилади.

### 8.4 Категориялар

Ҳужжат категориялари: STENOGRAM, PROTOCOL, PHOTOROBOT, VIDEO, CASE_FILE, ACCIDENT_REPORT — дастурда сақлаш пайтида танланади.

Дастур кодига таъсир қилмайди: фақат архив модулининг иш тарзи тавсиф этилади.

## 9. АВТОҲАЛОКАТ ВИЗУАЛЛАШТИРИШ (ВИДЕО ЭКСПЕРТИЗА)

### 9.1 Мақсад

Тергов учун етказилган расмлар (хулоса, транспорт воситалари, ҳаво, вақт) асосида AI томонидан автохалокат сценини таҳлил қилиш ва 4 та кадрда реконструкция қилиш; натижани кўриш ва архивга сақлаш.

### 9.2 Расм юклаш

- Бир ёки бир нечта расм юкланади; HEIC формати қўллаб-қувватланади (конвертация орқали).
- Юклашдан кейин «Таҳлил» (ёки аналогик) тугмаси босилади.

### 9.3 AI таҳлили

Ташқи API (OpenRouter, vision) орқали расм(лар) таҳлил қилинади; чиқади: хулоса, транспорт воситалари типи, тезлик баҳоси, ҳаво, кундузги/кеча. Натижа матн майдонида кўрсатилади ва фойдаланувчи таҳрирлаши мумкин.

### 9.4 Камера кўриниши ва кадрлар

- Камера тури танланади: CCTV, Dashcam, Drone, гувоҳ телефони ва ҳ.к.
- «Кадрлар яратиш» тугмаси босилганда 4 та эксперт кадр генерация қилинади (ҳар бири сценанинг белгиланган босқичи).
- Кадрлар кетма-кет кўрсатилади; «Плей» орқали кўриш имконияти бор.

### 9.5 Сақлаш

Натижа (кадрлар ва тавсиф) архивга сақланади; категория — ACCIDENT_REPORT.

## 15. ТАШҚИ ХИЗМАТЛАР ВА API

### 15.1 OpenRouter

- Матн (чат, транскрипция тузатиш, спикер аниқлаш, баённома генерация, мураббий, ҳуқуқий қидирув, академия викторина, расм таҳлили ва ҳ.к.) ва расм генерация (фоторобот) учун ишлатилади.

- Моделлар: матн учун (масалан: Gemini), расм учун (Gemini Flash Image, Flux ва ҳ.к.) конфигурацияда ёки кодда белгиланган.

### 15.2 Groq

- API калити `GROQ_API_KEY` орқали берилади.

### 15.3 Open-Meteo

- Ҳаво маълумоти (Фарғона) учун ишлатилади; аутентификация талаб этилмайди, фақат HTTP сўров.
